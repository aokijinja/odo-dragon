GitHub Pagesへの配置
GitHubのリポジトリの公開元に odo-ar フォルダを作り、
index.html、ar.js、sign.mind、Aoki_Odo_Dragon_Silver_Blue_v22.glb の
4ファイルを同じ階層に置いてください。現在のトップページの編集は不要です。

iPhoneだけで公開するときは、まず「ファイル」アプリでZIPをタップして
展開します。SafariでGitHubにログインし、リポジトリの「Add file」から
「Create new file」を選び、ファイル名に odo-ar/README.txt と入力して、
この説明文を保存すると、odo-ar フォルダが作られます。
そのフォルダを開いて「Add file」→「Upload files」で上の4ファイルを
選び、「Commit changes」で保存してください。

現地での確認
iPhoneのSafariで公開先を開き、「ARをはじめる」を押してカメラを許可。
参道側から白い「小戸池」の案内板の文字面を画面に入れてください。
認識したら、案内板を画面の端に残しつつ、池と龍が入る構図を確認します。
写真の青丸を目安に仮配置済みです。現地の水面に尾の先を合わせるには
ar.js の placement の位置と高さを調整します。数値の単位は看板の横幅です。
QRコードを使う場合は、現地で確認できた公開URLをQRにします。
