檍神社 小戸の池の龍神さま｜AR.js比較版

【iPhoneでGitHub Pagesに追加】
1. 「ファイル」アプリでZIPをタップして展開します。
2. Safariで GitHub の aokijinja/odo-dragon リポジトリを開きます。
   https://github.com/aokijinja/odo-dragon
3. main のトップで Add file → Create new file を開きます。
   ファイル名に odo-arjs/README.txt と入力し、本文を入力して保存します。
4. 新しくできた odo-arjs フォルダを開き、Add file → Upload files で
   展開した odo-arjs フォルダ内の次の7ファイルを置きます。
   index.html
   comparison.js
   camera_para.dat
   sign.iset
   sign.fset
   sign.fset3
